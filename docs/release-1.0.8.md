# Wearbuddy 1.0.8

- ACP：先检查实际 HTTP 状态和事件流类型；连接失败时刷新会话凭据，最多重试三次，不重放任务消息。
- 产物：按当前官方网页的方式优先读取沙箱 `/workspace` 文件，再尝试对象存储预签名链接；区分账号和会话缓存，避免同名文件串用。
- 账号：点击资料卡或套餐卡进入管理页；底部官方 EdgeButton 提供“＋添加账号”。多个账号各自保存登录凭据，新增登录完成前保留当前账号。当前账号采用主色按钮（默认蓝色），其他账号采用深灰色 tonal 按钮。
- 文件：内置文件夹浏览器支持选择文件和图片，更换头像也使用内置选择器，不依赖手表上的系统文件管理器。应用产物目录可直接读取；公共目录可通过页面按钮申请存储权限。
- 界面：新页面使用官方 Wear Compose Material 3 的 ScreenScaffold、TransformingLazyColumn、Button 和 EdgeButton；设置行和提示也改用官方组件。

验证：24 项单元测试、4 项圆屏模拟器测试通过，Release 构建和 APK 签名验证通过。

真实账号的短信登录、ACP 云端执行与产物下载仍需在已登录的手表上验证；模拟器验证不代表这些云端流程已实测成功。文本和图片沿用应用内预览，其他文件可保存到手表。
