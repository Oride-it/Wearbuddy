# Wearbuddy 1.0.9

- “我的”页面顺序调整为：当前账号资料、账号管理、版本套餐。
- 设置项前置图标统一为灰色。
- 底部增加“检测更新”，顺序为检测更新、关于、退出登录。
- 每次进入应用自动检查 GitHub 正式发行版，有更新时显示版本号和更新内容。
- 使用官方 M3E 确认/取消按钮及横向下载进度，下载后验证大小、SHA-256、包名、签名和版本并打开系统安装界面。
- 继续使用固定正式版 KEY，开启 R8 混淆、代码收缩、优化和资源压缩。

首次需要手动安装本版本，之后可在应用内检测新版本。系统安装界面仍需要用户确认。


验证：27 项 JVM 单元测试和 6 项圆形 Wear OS API 33 模拟器测试通过，签名版 Release 构建成功。
本版本签名证书与 1.0.8 相同，可覆盖升级。GitHub 首次发布及真实设备系统安装流程需要发布源与设备支持。
