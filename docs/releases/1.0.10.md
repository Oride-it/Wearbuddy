# Wearbuddy 1.0.10

- 根据官方 Android APK 的 Dart AOT 分析结果修正产物下载协议。
- 支持 `/root/` 产物路径，兼容 `sandboxDataLink` 和沙箱文件服务地址推导。
- 沙箱文件读取使用会话令牌，不再附加固定的 `username=user`。
- 文件服务返回 401、403 或 404 时重新获取会话并重试一次；沙箱路径不再作为 COS 对象键重试。

31 项 JVM 单元测试（含本地 HTTP 回归测试）通过，Debug 和签名 Release 构建通过。
签名证书与 1.0.9 一致，可覆盖升级；真实账号产物下载仍需登录设备验证。
