# Wearbuddy 1.0.14

安装包沿用原正式签名，可从 1.0.13 覆盖安装。正式版启用了 R8 优化、代码混淆和资源压缩。

- **聊天页全屏滚动。** 时钟背景透明，消息可从底部悬浮按钮后方滑过，滚到末尾会为最后一条消息留出空间。底部保留「选择模型」和「发消息」，语音输入在「发消息」页使用。
- **模型选择页优化。** 卡片滑到屏幕中央时逐渐放大，靠近边缘时缩小。模型名称改为单行显示，长名称在列表停稳后横向滚动。
- **修复工作区目录误报 HTTP 415。** 按一级读取目录，空目录会正常显示，读取失败时会保留实际错误。列表卡片间距统一为 6 dp，图标和文字垂直居中。
- **精简「思考过程」卡片。** 收起时减少留白，展开后整张卡片均匀高亮，正文仍可长按复制。
- **更新「关于 Wearbuddy」。** 应用图标、版本和设备型号集中展示，版本号与设备名改用较细的常规字重。补充应用介绍、MIT 许可证、GitHub 地址和 Oride 的头像，滚到底部可点圆弧形「返回」按钮回到「我的」。

工作区目录修复已通过本地回归测试，仍待在实际云端工作区验证。
