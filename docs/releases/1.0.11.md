# Wearbuddy 1.0.11

- HTML / HTM 产物支持网页预览：设备有网页引擎时在应用内打开，否则交给浏览器；没有可用浏览器时提示并保留文件。
- 长按复制任务完整标题、聊天内容、产物文件名和文本预览。
- “应用介绍”标题改为白色，介绍区稍微上移并调整边距。
- 任务卡片按文字内容收紧高度，减少底部空白，保留至少 48dp 点击区域。
- 修正执行状态与沙箱状态的优先级，避免旧“执行中”状态覆盖已完成状态；手动停止记录按账号保留，重启应用后继续生效。
- 修复更新下载百分比变化而进度条不动的问题，移除进度条右端的独立圆点。

验证：36 项 JVM 单元测试、10 项圆形 Wear OS API 33 设备测试通过。
设备测试包含进度条实际像素变化、完整文本复制、卡片高度、白色介绍标题和缺少网页引擎/浏览器时的兼容处理。
模拟器没有网页引擎，完整网页渲染和外部浏览器打开仍需支持这些功能的设备验证。
真实账号任务状态同步仍需登录设备验证；关闭页面本身不会停止云端任务。

正式版沿用原签名，开启 R8 混淆、代码优化/收缩和资源压缩，可覆盖升级。
