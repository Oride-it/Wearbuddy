# Wearbuddy 1.0.13

安装包沿用原正式签名，已开启 R8 混淆、代码收缩和资源压缩，并验证可从 1.0.12 覆盖安装。

- 会话首页按参考图改用 Wear M3E 组件：「新对话」位于上方，已有会话显示为胶囊按钮。创建会话后空态提示消失，进入对话才显示模型、语音和文字输入。
- 阅读时不会被新输出拉走，点「回到底部」即可跳到末尾查看产物。
- ACP 临时断线会自动重连，保留已显示的消息，不再反复弹窗，也不会重复发送指令。
- 产物直接保存到手表公共 `Download` 根目录，同名文件不会覆盖。内置文件选择器会列出实际可访问的目录，已通过 AppOps 授权时不再提示前往设置。
