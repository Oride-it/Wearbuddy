# Wearbuddy 1.0.12

- 产物下载成功后保存到手表公共 `Download/Wearbuddy/账号目录/`，界面明确显示下载位置。
- 保留应用内预览副本，图片和 HTML 预览沿用原来的读取方式。
- 旧版已经下载的文件，再次点开时会直接从本地复制到公共下载目录，无需重新下载。
- 重复下载相同文件复用现有公共文件；手动删除公共文件后再次下载会重新保存。
- 账号和任务分别参与目录及文件名生成，避免同名产物相互覆盖。
- Android 10 及以上使用 MediaStore Downloads；旧系统增加保存前的存储权限申请，不申请全盘访问来写入下载文件。

验证：36 项 JVM 测试和 Wear OS API 33 上 4 项公共下载设备测试通过，签名 Release 构建通过。
设备测试核对公共路径、完整文件字节、已发布状态、预览兼容、旧文件复制、重复下载及删除后的重新保存。
旧系统权限分支尚未完成设备验证。原有完整界面套件本次受其它应用抢占前台影响，文件选择器用例未通过；公共下载的专项测试均通过。

沿用原正式版签名，开启 R8 混淆、代码优化/收缩及资源压缩，可覆盖升级。

存储实现参考 [Android 公共文件和下载目录文档](https://developer.android.com/training/data-storage/shared/media)。
